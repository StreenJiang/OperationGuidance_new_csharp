# 任务名称嵌入 ID 前缀

任务名称在保存时自动添加 `{id} - ` 前缀（如 `123 - 拧紧任务A`），编辑框中显示时自动剥离。前缀格式选择了裸 `{id} - ` 而非 `【{id}】`，因为简洁且与现有命名风格一致。

**Status:** accepted

## Considered Options

**存储在单独列**（`display_name` / `name` 分离）：新增 `display_name` 列存储无前缀名称，`name` 列保持带前缀。放弃原因 — 改动面大（DB migration + 所有读写路径），需求本身简单不值得。

## Consequences

- 所有后续保存的任务名称都会带 `{id} - ` 前缀，修改前缀格式需要数据迁移
- 任务列表、导出等直接展示 `name` 的地方会自动显示带前缀的名称，无需额外处理
- 旧数据（无前缀）在下次编辑保存时自动补齐
