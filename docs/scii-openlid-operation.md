# SCII / SCII_XT 螺丝机分组扫码开盖

SCII 与 SCII_XT 共用分组扫码开盖功能。管理员提前完成配置，操作员选择需要打开的盖子并扫描对应条码。

## 管理员配置

1. 进入“系统设置”，向下滚动找到“螺丝机开盖配置”。
2. 填写开盖组名称、开盖条码、点位，并选择对应的螺丝机组。
3. 点位范围为 1～8，同一螺丝机组的点位不能重复；填写了一项的组必须补全所有字段。
4. 使用加号新增组，使用减号删除对应组，完成后点击“保存”。
5. 逐组检查条码与实际盖子是否对应。

配置沿用设置页的现有权限。需要使用“IO点位测试”时，由管理员输入管理员操作密码。

## 操作员开盖

1. 在工作台点击底部的螺丝机图标。
2. 在“螺丝机开盖”区域找到对应名称，点击“点击开盖”。
3. 在扫码窗口扫描该组的开盖条码；条码匹配后系统发送开盖指令，随后关闭窗口。
4. 确认实际盖子已打开，再继续后续操作。

扫码开盖无需管理员密码。条码不匹配时按提示重新扫描；选错组时点击“取消”后重新选择。窗口关闭后恢复正常生产扫码。

没有显示开盖组、按钮不可用或扫码后设备未动作时，联系管理员检查配置和设备。窗口关闭表示流程已执行到关闭步骤，实际开盖情况以设备为准。

## 配置兼容

两个版本均使用运行目录中的 `SciiXtArrangerConfig.ini`，字段与原 SCII_XT 配置一致，原配置可以继续使用。不同运行目录独立保存；同一运行目录切换版本时共用配置。

SCII 的配置区域位于普通任务设置下方，SCII_XT 位于 MES 设置下方。SCII 等待任务 NG 管理员确认时，串口扫码仍遵循原有拦截规则。
