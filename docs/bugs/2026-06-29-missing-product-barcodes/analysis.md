## 关键证据

### 证据 1：日志中完全不存在

系统的扫描日志链路为：

```
BarCodeInputPopUpForm_SCII
  → "Already chosen mission, barcode = [xxx]"        ← 扫码后第一条日志
  → SQL 查重
  → "All checks passed" 或 "Check fails"              ← 校验结果
  → "Mission record created, barcode = xxx"           ← 入库成功
  → ToolTask "Sending barcode [xxx]"                  ← 发送工具
```

这 7 个码在上述任何一步都没有出现。**连第一步 `Already chosen mission` 都没有，说明扫码枪从未输出这些码。**

### 证据 2：相邻码出现次数正常

每个正常产品码在日志中出现次数为 **15 次**（含扫描、校验、工具数据上报等）。所有缺失码的相邻码均为标准的 15 次，排除了扫码枪误读的可能（误读会导致相邻码计数异常偏高）。
